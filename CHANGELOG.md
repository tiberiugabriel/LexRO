## [1.0.0] - 2026-10-09

First public release.

### Added

- LexRO skill for e-commerce, online platform and GDPR compliance in Romania and the EU.
- Workflow: classification, prioritised intake, hidden-domain detection, live verification on official Romanian and EU sources, answers with confidence levels, escalation to the right specialist.
- Reference files for consumer law, platforms, products and imports, data protection, cookies and marketing, tax, payments, security, AI and data, IP, competition and advertising.
- Acts registry as a starting map (compiled by an AI model, not verified act by act).
- Bilingual (English and Romanian) README and installation guide.
- `dist/lexro.skill` package for the Claude app, and one-command installers for Claude Code (`install.sh`, `install.ps1`).
- License: Apache License 2.0 with the Commons Clause condition.
- Contributor guide, issue templates (legal inaccuracy, coverage request, bug report) and a local CI script (`scripts/ci.sh`).
